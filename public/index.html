🌐 Uso en Red Local (Computador y Celulares)

Para usar este software en teléfonos y otros computadores conectados a la misma red Wi-Fi o red local:

  1. Mantén el computador principal con este servidor ejecutándose.
  2. En tu celular o tablet conectada a la misma red Wi-Fi, abre el navegador (Chrome, Safari, Edge).
  3. Ingresa la dirección IP de tu computador mostrada en la consola, por ejemplo: http://192.168.x.x:3000.
  4. ¡Listo! El celular verá en tiempo real el dashboard y los ingresos en vivo que realiza el lector USB.
